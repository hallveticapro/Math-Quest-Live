# MathQuest Live

A classroom-safe AI-powered math adventure game for 4th grade students where kids solve math to advance through an 8-turn fantasy story.

## Run & Operate

- `pnpm --filter @workspace/api-server run dev` — run the API server (port 8080)
- `pnpm --filter @workspace/mathquest-live run dev` — run the frontend (port 18567)
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- Required env: `AI_INTEGRATIONS_OPENAI_BASE_URL`, `AI_INTEGRATIONS_OPENAI_API_KEY` — set by Replit AI integration

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- Frontend: React + Vite + Tailwind CSS + shadcn/ui
- API: Express 5
- AI: OpenAI via Replit AI Integration (no user API key required)
- Validation: Zod (`zod/v4`), `drizzle-zod`
- API codegen: Orval (from OpenAPI spec)
- Build: esbuild (CJS bundle)

## Where things live

- `lib/api-spec/openapi.yaml` — API contract (source of truth)
- `lib/api-client-react/src/generated/` — generated React Query hooks
- `lib/api-zod/src/generated/` — generated Zod schemas for backend validation
- `artifacts/api-server/src/routes/game/` — game story routes (start, turn, ending)
- `artifacts/api-server/src/routes/game/storyPrompt.ts` — AI prompt builder
- `artifacts/api-server/src/routes/game/safety.ts` — content safety filter
- `artifacts/mathquest-live/src/` — React frontend
- `artifacts/mathquest-live/src/mathEngine.ts` — deterministic math problem generator

## Architecture decisions

- Math is generated by deterministic client-side code (never by AI) — ensures correctness and avoids AI hallucinations on math
- AI only generates story text, scene titles, choices, and endings — no math
- All AI calls go through the backend only — OpenAI API key never exposed to browser
- No database, no login, no persistence — game state lives in browser memory only; page refresh resets the game
- Content safety has two layers: strict system prompt rules + server-side banned-word filter with fallback scenes

## Product

4th grade classroom game: students pick a hero (name, pronouns, ancestry, class), choose an adventure theme and difficulty, then play an 8-turn AI-narrated story. Each turn they pick one of 3 action choices, then must solve a math problem to advance. After 8 solved turns, they receive an AI-generated ending and a badge.

## User preferences

- No student freeform input anywhere in the app
- Classroom safe (ages 9-11): no violence, horror, romance, drugs, etc.
- Math is deterministic code, not AI-generated
- Page refresh resets game (no persistence)

## Gotchas

- After changing `lib/api-spec/openapi.yaml`, always run `pnpm --filter @workspace/api-spec run codegen` before using updated types
- The `lib/api-zod/src/index.ts` uses `export type *` for generated types to avoid duplicate export conflicts with Zod schemas
- AI model is configurable via `OPENAI_MODEL` env var (default: `gpt-5-mini`)
