# MathQuest Live Playability Review

## Student Experience Findings

MathQuest Live has a strong MVP loop: students choose preset hero options, read a short adventure scene, pick from three safe action buttons, and solve a code-generated math problem before the story advances.

The game becomes engaging once the story begins, but the setup flow has several dropdowns before students reach the first exciting moment. For upper elementary students, the first win should arrive quickly.

Current strengths:

- The fantasy adventure theme is clear and kid-friendly.
- Students interact through buttons only.
- The story/action/math loop is easy to understand.
- Hero choices and adventure seeds create some replay value.
- Endings and badges provide a basic sense of completion.

Main opportunities:

- Add a visible progress indicator, such as `Chapter 3 of 8`.
- Add small reward moments after correct answers.
- Make endings reflect the selected challenge level and solved challenges.
- Connect math skill categories more tightly to story flavor so math feels less bolted on.

## Classroom Usability Findings

The app is mostly classroom-friendly for centers, early finishers, review, enrichment, intervention, or whole-class display. Buttons are large, setup options are preset, and game state resets on refresh.

Current strengths:

- No accounts, login, rosters, database, analytics, or saved student progress.
- Students can use the app independently after basic instructions.
- The default 8-turn structure is close to a practical classroom activity.
- Exit and replay paths exist.

Main opportunities:

- Rename story length options around classroom time: `Quick Quest`, `Standard Quest`, and `Full Quest`.
- Consider lowering the longest mode from 15 turns to 10-12 turns.
- Make reset/new quest controls more teacher-obvious.
- Improve loading states so AI response time feels intentional rather than like waiting.

## Math Playability Findings

The current math system is much stronger than the original version. Math is generated by app code, correct answers are calculated deterministically, answers are shuffled, and generated problems include Florida B.E.S.T. metadata.

Current strengths:

- Difficulty now acts as a standards band.
- `Easy` maps to Grade 3 Florida B.E.S.T. content.
- `Medium` maps to Grade 4 Florida B.E.S.T. content.
- `Hard` maps to Grade 5 Florida B.E.S.T. content.
- `Extreme` remains advanced Grade 5 rather than middle school math.
- Every generated problem includes difficulty, grade band, benchmark, benchmark description, standards system, and skill metadata.
- The validator checks for benchmark metadata, grade band, four unique choices, and correct answer inclusion.

Main opportunities:

- Add skill-specific hints instead of the current generic recovery message.
- Add more generators per band to reduce repetition.
- Use more misconception-based distractors, especially in Hard and Extreme.
- Add optional skill focus inside each standards band for teacher use.
- Pass math skill metadata into story continuation so the AI can flavor the next scene without generating math.

## Accessibility Findings

The visual style is distinctive and readable in many places, but there are some accessibility risks.

Current strengths:

- Buttons are large.
- Core controls are button/select based.
- Story text uses `whitespace-pre-wrap`, so paragraph breaks from the AI can display.
- The new app info modal uses a standard dialog component.

Main opportunities:

- Add strong `focus-visible` styling for `.rs-button`.
- Make feedback clear without relying on color or sound.
- Soften incorrect-answer text from `Incorrect. Try again!` to something more supportive, such as `Not yet. Try again.`
- Watch lower-contrast muted text, especially `#8c7a55` on dark backgrounds.
- Keep Easy scenes short enough for Grade 3 readers.

## Kid-Safety Findings

The safety model is solid for an MVP. The app does not allow freeform student story input, and the backend validates AI output before sending it to the frontend.

Current strengths:

- The AI prompt forbids gore, death, romance, profanity, horror, bullying, stereotypes, politics, religion, drugs, alcohol, vaping, sexual content, self-harm, and personal information requests.
- The prompt tells the AI not to generate math.
- The prompt requires exactly three choices.
- Backend validation checks JSON shape, `kid_safe` safety rating, choice count, choice IDs, string lengths, banned words, and HTML tags.
- Safe fallback scenes and endings exist.
- Ancestry/species and pronouns are constrained to preset options and treated as flavor.

Main opportunities:

- Add approximate word-count validation by difficulty band.
- Add multiple fallback scene variants so fallback output feels less generic.
- Log invalid AI output reasons server-side for debugging.
- Keep benchmark metadata out of student-facing UI by default.

## Pacing Findings

The current turn options are 8, 11, and 15 chapters. For a 10-15 minute classroom activity, 15 chapters may run long, especially with AI latency after each correct math answer.

Recommended pacing model:

- `Quick Quest`: 5 turns
- `Standard Quest`: 8 turns
- `Full Quest`: 10-12 turns

Main opportunities:

- Rename the current length selector to use classroom-friendly quest labels.
- Add visible progress during gameplay.
- Make loading screens more playful.
- Verify exact turn-count behavior so the label matches the number of math gates students experience.

## Replayability Findings

The app already has several adventure seeds, hero names, ancestries, classes, and endings. Replayability is good enough for MVP, but it can improve without adding accounts or saved data.

Current strengths:

- Adventure seeds are varied and classroom-safe.
- Hero setup adds identity and fantasy flavor.
- AI-generated scenes can vary across plays.

Main opportunities:

- Add seed-specific fallback scenes.
- Add random safe companions, artifacts, or quest objects from fixed lists.
- Generate end badges based on adventure seed, challenge level, and solved math skills.
- Let math skill categories influence story flavor, such as geometry problems appearing as maps, bridges, rooms, angles, or blueprints.

## Teacher-Control Recommendations

Keep teacher controls simple and stateless. Do not add accounts, dashboards, rosters, grading, analytics, or saved progress for the MVP.

Good MVP teacher-facing controls:

- Challenge level / standards band.
- Quest length.
- Adventure theme.
- Optional math skill focus within the selected standards band.
- Reading length.
- Display mode for whole-class use.
- Sound on/off if sound becomes more prominent.
- Safe fallback-only mode if AI is unavailable.
- Optional teacher/debug display of Florida B.E.S.T. benchmark metadata.

## Prioritized Improvement List

### Critical Fixes

1. Audit Florida B.E.S.T. benchmark codes and descriptions against CPALMS.
   - Why it matters: Teacher trust depends on conservative, accurate standards claims.
   - Florida B.E.S.T. impact: Prevents unsupported benchmark descriptions.
   - Estimated difficulty: Medium.
   - Target: MVP.
   - Likely files: `artifacts/mathquest-live/src/math/floridaBestMath.ts`, `README.md`.

2. Verify exact turn-count behavior against quest labels.
   - Why it matters: Classroom timing must be predictable.
   - Florida B.E.S.T. impact: Indirect; affects how much standards practice happens per play.
   - Estimated difficulty: Low.
   - Target: MVP.
   - Likely files: `artifacts/mathquest-live/src/App.tsx`, `artifacts/mathquest-live/src/pages/SetupScreen.tsx`.
