# Florida B.E.S.T. Domain Expansion Plan

## Purpose

This is a planning document for future code-generated math variety in MathQuest Live. It describes how to expand generator coverage by challenge band, skill area, and verified benchmark direction without overbuilding the MVP or drifting outside grade-level expectations.

This plan does not change app behavior. It does not add generators, change benchmark mappings, or make new standards claims.

Future implementation should continue the current model:

- Math is generated by code, not AI.
- Challenge level equals the Florida B.E.S.T. standards band.
- Easy / Adventurer maps to Grade 3.
- Medium / Hero maps to Grade 4.
- Hard / Champion maps to Grade 5.
- Extreme / Legend stays inside advanced Grade 5 expectations.

## Suggested Expansion Order

The order below favors classroom value, low implementation risk, and better play variety.

## Guardrails

- Do not use AI-generated math.
- Do not use Grade 6 standards in Extreme.
- Do not add negative numbers.
- Do not add slope.
- Do not add linear equations.
- Do not add ratios or proportional relationships beyond Grade 5 expectations.
- Do not add exponents beyond the verified Grade 5 expression expectations.
- Do not add probability or middle-school statistics content.
- Every problem must include benchmark metadata.
- Every problem must include a stable signature.
- Duplicate detection must ignore shuffled answer choices.
- Every generated problem must avoid repeats within a quest when possible.
- Every generator must provide a skill-specific first hint and second hint.
- Every answer set must include exactly four unique choices.
- The correct answer must appear in the choices.
- Distractors should reflect common misconceptions without being unfair.
- Recovery problems should also participate in repeat prevention where possible.
- Student-facing UI should not be cluttered with benchmark codes by default.
- Formal standards claims should wait for CPALMS/FDOE verification and documentation updates.

## Implementation Prompt Groups

### Easy Expansion Prompt

Add Grade 3 generators for place value, rounding, measurement operations, and simple data interpretation. Use only verified benchmark metadata. Keep one-step and light two-step problems. Add stable signatures, unique answer choices, and skill-specific hints.

Recommended order:

1. Place value
2. Money or measurement
3. Data interpretation
4. Additional elapsed-time variety

### Medium Expansion Prompt

Add Grade 4 generators for factors/prime/composite, area/perimeter, fraction operations, money, measurement conversion, data interpretation, decimal comparison, and additional angle/geometry variety. Keep each generator within verified Grade 4 expectations and avoid introducing Grade 5 fraction complexity.

Recommended order:

1. Factors/prime/composite using `MA.4.AR.3.1`
2. Area/perimeter and missing rectangle sides using `MA.4.GR.2.1`

### Hard Expansion Prompt
